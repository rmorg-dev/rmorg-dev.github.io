# Professional Self-Assessment
## Introduction
My name is Reagan Morgan. I have been a full-time student at SNHU since 2024 working towards my B.S. in Computer Science. Previously, I was a student at the University of Oklahoma. After I graduate, I plan to pursue jobs in the tech industry related to C++ so I can get hands-on work while continuing to develop my skills in electronics so I can ultimately pursue a career in embedded software engineering.
## Educational Reflection
Throughout my college career at SNHU, the skills that I have developed include Data Structure and Algorithms, C++, Java, and best coding practices. Completing the work for this ePortfolio as well as throughout my SNHU career has helped me recognize my strengths and interest in C++ and low-level development as well as helping me identify areas I want to continue growing in like electronics. My professional goal is to become an embedded software engineer and work mainly with C++. I value problem-solving, constant growth, and learning new things as a professional. 

Within this program, I did not have any direct collaboration with my peers through things like groupwork. However, at my previous institution (The University of Oklahoma), I learned how to collaborate in my Computer Architecture class. This class was comprised of mostly groupwork creating and learning about breadboards. It taught me how to effectively communicate my ideas and problem-solving steps with others. It also helped me understand conflict resolution when we would disagree about how to implement something. At SNHU, I learned how to effectively communicate with stakeholders in my CS250 Software Development Lifecycle course. This course required me to create Software and System Design documents in non-technical language to better represent complex ideas for those who may not understand the technical terminology.  

My CS300 Data Structures and Algorithm course helped me understand the fundamental concepts behind Big O Notation and how to analyze the efficiency of a data structure or algorithm. The final project of this course helped me showcase these skills by choosing and implementing the best option based on my Runtime analysis of 3 different types of data structures to choose from.  

Most of my courses at SNHU revolved around software engineering, but the course that developed my skills the most was CS320 Software Testing and QA. This class really helped me understand what I was coding as well as recognize potential edge cases that I need to check for when developing applications. It also taught me about testing coverage and how to interpret the results for JUnit tests. The most impactful class for databases was my DAD220 Intro to Structured Database Environments class. Before coming into this class I did not know anything about SQL. After taking this class, I understood how relational databases work and how to set them up. My CS305 Software Security class taught me how to analyze vulnerabilities that occur in code. It also taught me how to understand and realize what vulnerabilities were truly critical that I can fix vs. vulnerabilities that have little impact on my code but still need to be checked and ignored. It also informed me of how encryption communications work and how to implement them in my code.

## How the artifacts tie together
The artifacts in this portfolio demonstrate my growth in three key areas: Software Development and Engineering, Data Structures and Algorithms, and Databases. Each area uses the same artifact to show a fully completed and developed project while implementing all three key skills. The artifact I am using is my final project from my CS300 Data Structures and Algorithms course. The original artifact was a simple console application that sorted a CSV file into a binary search tree and then printed out the nodes or searched for a node based on user input. I selected this artifact for all three to fully flesh out my ideas as well as showcase my C++ skills. For the first enhancement, software design and engineering, I focused on showcasing my skills in memory management, modularity, and UI/UX design principles. The second enhancement, data structures and algorithms, showcases my skills in data structure design, complexity analysis, and the analysis of trade-off amongst data structures. Finally, the third enhancement, databases, showcases my skills in database design, security, and resource-conscious decision making.  

All of these enhancements help demonstrate my abilities in low-level development, resource-conscious design, and memory management. They help show how I can apply the concepts I learned throughout my career at SNHU to my own design as well as my growth as a student and professional.
